  2. デメリット

このサイトのURLは g-monotukun.github.io というGitHub Pagesの無料アドレスです。無料で始められる一方、独自ドメイン（例：example.com）に切り替えるメリットもあります。

独自ドメインのメリット

  • 引っ越しできる：サーバーやサービスを変えても、同じURLのまま運営を続けられます。
  • 信頼感：サイト名と一致したURLは覚えてもらいやすく、名刺やSNSにも載せやすくなります。
  • 資産になる：記事への評価やリンクがドメインに蓄積されます。

デメリット

  • 年間の更新費用がかかります（ドメインの種類によって異なります）。
  • DNSの設定など、最初に少し手間がかかります。

始めどきの目安

「とりあえず試したい」段階なら無料アドレスで十分です。記事が増えて長く続けると決めたら、早めに独自ドメインへ移すと、後から引っ越すより手間が少なくて済みます。

GitHub Pagesも独自ドメインに対応しているので、ドメインを取得すれば今のサイトのまま切り替えられます。

※ドメインの料金は、初年度と更新時で異なる場合があります。申込み前に更新料金も確認しておきましょう。
