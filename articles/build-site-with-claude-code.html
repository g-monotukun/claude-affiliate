Claude Codeだけでこのサイトを作った手順

実践記録公開 2026年10月15日約1分で読めます

結論

プログラミングの知識がなくても、Claude Codeに日本語で頼めばサイトの作成から公開まで進められます。ただしASP登録や公開前のチェックなど、人がやるべき作業も残ります。

  • GitHub Pagesで無料公開する流れ
  • 人がやる必要があった作業

このサイトは、AIコーディングツール「Claude Code」に日本語で指示を出して作りました。実際の流れを記録します。

1. 方向性をリサーチさせる

「SNSで需要があり、これから収益にできそうなアフィリエイトを調べて」と頼み、ジャンル・集客方法・規制をまとめてもらいました。 その結果、AIツールの比較サイトとThreadsでの発信を組み合わせる方針に決めました。

2. GitHubのリポジトリを用意する

空のリポジトリを作り、Claude Codeのセッションにクローンしました。

3. サイトを作らせる

トップページ、運営者情報、プライバシーポリシー、記事ページをHTMLで作成してもらいました。広告表記（PR表記）は全ページに自動で入るようにしています。

4. GitHub Pagesで公開する

リポジトリの設定からGitHub Pagesを有効にすると、無料でサイトを公開できます。

人がやる必要があったこと

  • ASP（A8.netなど）への登録と本人確認
  • GitHub Pagesの有効化
  • 公開前の内容チェック

今後も、運営の過程をこのサイトで記録していきます。

よくある質問

プログラミングの知識は必要ですか？

なくても始められます。ただ、出来上がったものを確認して、直してほしい点を言葉で伝えることは必要です。

サイトの公開にお金はかかりますか？

GitHub Pagesを使えば無料で公開できます。独自ドメインを使う場合はドメイン代がかかります。

AIが書いた記事をそのまま公開してもいいですか？

公開前に内容が正しいか、広告表記があるかを人が確認するのがおすすめです。
