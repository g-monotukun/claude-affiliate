# Threads ピン留め用の投稿（季節ごと）

ピン留めはThreads APIでできないため、手動で投稿してピン留めする。
季節が変わったら差し替える（目安：12月・3月・6月・9月の初め）。
型：見出し【はじめての方へ】→ 読む人の悩み3つ → このアカウントで分かること → 投稿の時間 → 季節の記事リンク → PR表記

## 冬（12〜2月）帰省・年末年始・確定申告
【はじめての方へ】

こんなこと、ひとりで抱えてない？
・年末に帰省したら、親の様子が気になる
・ヒゲや肌の悩み、人に聞きにくい
・確定申告や仕事のツール選びで止まってる

このアカウントでは、人に聞きにくい「ちょっと困った」を、明日すぐ使える一言にして毎日届けてます
朝は豆知識、昼はみんなへの質問、夜はまとめ記事

いま一番読まれてる、帰省前のチェックリストはこっち👇
https://g-monotukun.github.io/parents-consultation/articles/homecoming-checklist.html

フォローしておくと、帰省前にも役立つよ
※記事リンクはPRを含みます
